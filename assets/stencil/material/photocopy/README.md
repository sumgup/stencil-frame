# photocopy

**Status:** AWAITING PRODUCTION — no assets yet.

## What belongs here

Textures and captures documenting the material behavior of photocopying:
halftone patterns, toner irregularity, reproduction noise, photocopy degradation.

## Why this material exists

Photocopying implies **reproduction** — a document that was copied, and in the
copying, degraded. Every asset in this folder should visibly carry that history.

## Rules

- Production assets only after they are created/photographed/scanned by us, or

- Do not add placeholder or fabricated textures. If nothing exists yet, this
  README is the only file in the folder.
