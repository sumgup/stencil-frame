# tracing

**Status:** AWAITING PRODUCTION — no assets yet.

## What belongs here

Textures and captures documenting tracing paper and translucent overlays:
translucent layers, supersession, visible previous states.

## Why this material exists

Tracing implies **supersession** — a new version laid over an old one, with
the old one still visible underneath. The asset should show that a decision
was revised, not erased.

## Rules

- Production assets only after they are created/photographed/scanned by us, or
  explicitly licensed for our use. See `assets/stencil/ASSET-MANIFEST.md`.
- Do not add placeholder or fabricated textures. If nothing exists yet, this
  README is the only file in the folder.
